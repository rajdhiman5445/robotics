## Definition of AI?
- System that thinks like human 
- System that thinks rationally 
- System that acts like human
- System that acts rationally

# Approach 1: Thinking Humanly 
- Requires knowledge of brain function
- Aim is to Replicate human thought processes
- This is the focus of Cognitive Science 

# Approach 2: Acting Humanly 
- Turing test: ultimate test for acting humanly (what is it really?)
- Computer and human both interrogated by judge
- Computer passes if judge can't tell the difference 

# Approach 3: Thinking Rationally 
- Laws of Thought Approach
- Using formal logic to arrive at correct conclusions 

# Approach 4: Acting Rationally 
- "Rational Agent" Approach 
- Aim: Maximize goal achievement based on information and actions 
- Focus: Don't mimic humans but perform that action that leads to the best outcome 

# History of AI 
- Dartmouth Conference in 1956 started the CS based AI
- John McCarthy - term AI and developed LISP, application of logical reasoning 
- Marvin Minsky - Advance neural Network
- Claude Shannon - Worked in game playing AI (checkers and chess) 
- Allen Newell and Herb Simon - universal problem solving machine 

# AI Learning Processes 
- Recognizing patterns, Unsupervised learning

# Component of an AI System 
- Agent perceives its environment through sensors and acts on the environment through actuators. 
- Action of agent causes changes in the environment 
- Agent do the reasoning if the change was positive or negative 

# Rational Agent 
- Agent is intelligent only if it chooses action that maximize its success, based on its current knowledge. This is a rational Agent. 
- to judge if it's doing well, we define a fixed performance measure. 

# P.E.A.S = Performance measure, Environment, Actuators, Sensors 
- PEAS is a framework used to define AI problems clearly and completely.
